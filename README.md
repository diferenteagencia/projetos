# Dashboard de Projetos — publicação no GitHub Pages

Esta pasta já contém todos os arquivos necessários para a dashboard funcionar:

- `index.html`
- `styles.css`
- `app.js`
- `projects-data.js`

## Como publicar

1. Crie ou abra o repositório no GitHub.
2. Envie **todos os arquivos desta pasta para a raiz do repositório**, mantendo os nomes exatamente como estão.
3. No repositório, acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**, escolha `main` e a pasta `/(root)`.
5. Salve e aguarde o GitHub informar o endereço publicado.

> Importante: não envie apenas o arquivo `index.html`. Os arquivos `styles.css`, `app.js` e `projects-data.js` precisam estar na mesma pasta dele; caso contrário, a página fica sem design e sem dados.
